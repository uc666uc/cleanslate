# CleanSlate Cleaner

A portable Windows 10/11 x64 junk and script cleaner.

## Features
- Junk cleaner for Temp folders
- Script scanner (Desktop, Downloads, Documents)
- Preview before delete — never silent
- Browser cache cleaner (Chrome, Edge)
- Confirmation required for every destructive action

## Usage
1. Download the artifact from the Actions tab
2. Unzip
3. Double-click `CleanSlate.exe`

No install. No admin. No background processes.
